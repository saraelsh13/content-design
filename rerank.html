Developer explainer · Independent sample

When should you use Context Focus?

Use Rerank 5 to reorder candidate documents. Evaluate Context Focus when you also need to find the most relevant passages inside those documents.

Why teams might test this feature

A company’s search tool can return several relevant documents when an employee asks a question. Cohere’s Rerank puts the strongest matches first. Context Focus helps a team find useful passages inside those matches. This guide shows how to compare full documents with selected passages before changing a live workflow.

Start with the Cohere overview and journey map

Suppose your application searches an employee handbook for the rules on carrying over leave. Your initial retriever finds the handbook, a benefits overview, and an older policy. A reranker can move the most relevant documents up the list. Context Focus adds a second piece of information. It can return character spans within a result that help your application find the passages to show or pass to a language model.

Run the same query two ways

Reuse the same candidate documents and model for both requests. This isolates the change you’re testing. The request body below uses fictional policy text and the fields in Cohere’s Rerank 5 release notes. Send it to POST /v2/rerank using your own authenticated client. For the baseline, omit relevant_spans. It is off by default.

{
  "model": "rerank-v5.0-pro",
  "query": "How many days of annual leave can I carry over?",
  "documents": [
    "Employees may carry over up to five days of annual leave.",
    "Submit annual leave requests in the employee portal."
  ],
  "top_n": 2,
  "relevant_spans": { "mode": "enabled", "threshold": 0.3 }
}

Where passages meet the threshold, the response can include their start and end character offsets and a relevance score. Inspect both the returned passage and its surrounding text. A sentence can be relevant on its own and still omit a date, exception, or eligibility condition that changes the answer. If your application receives no usable span, test a fallback that passes the full authorized document or expands the surrounding context.

Decide on evidence from your own corpus

QuestionWhat to measure
Did we preserve the answer?Have reviewers label the key passage and any exception. Score whether both survive in the context your application sends.
Did we spend less?Compare median and p95 retrieval latency, input tokens, and end-to-end task latency for full-document and span-based versions.
Where should we use it?Review short fact lookups separately from tasks that require multiple sections, tables, or qualifications.

Use the same evaluation set to compare Pro and Fast after you’ve decided how to handle spans. The example threshold is a starting point from the release notes. Tune it against your own corpus and the cost of missing a necessary passage.

The request is adapted from public documentation. It was reviewed against the published example and was not executed against Cohere’s API.
